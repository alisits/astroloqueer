# Astroloqueer frontend

React + TypeScript + Vite, styled with Tailwind CSS and shadcn/ui.

## Development

```sh
npm install
cp .env.example .env   # points the app at your backend API
npm run dev
```

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – production build (output in `dist/`)
- `npm run lint` – run ESLint
- `npm run preview` – preview the production build

The production build is deployed with Netlify; see `netlify.toml` in the repository root.
